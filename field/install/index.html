Add it to your home screen before you sign in. The installed app keeps its own login, so signing in while you are still in the browser means doing it a second time. The app itself will walk you through this when it opens.

iPhone

  1. Scan the code — Safari opens.
  2. Tap the Share button at the bottom, the square with the arrow.
  3. Scroll down, tap Add to Home Screen, then Add.
  4. Open HouseMaster from your home screen and sign in there.

Android

  1. Scan the code — Chrome opens.
  2. Tap Install now if it offers, or the ⋮ menu.
  3. Tap Install app, then Install.
  4. Open HouseMaster from your home screen and sign in there.

Sign in with your work email. If you do not have a password yet, the office sets one up under Records → Employees.
